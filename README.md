# 小樽運河クルーズ空席監視（LINE + GitHub Actions）

このフォルダをGitHubリポジトリにアップロードすると、5分おきに小樽運河クルーズの予約画面を確認し、空席が出たときだけLINEへ通知します。

## 監視条件
- 2026-10-20：ナイトクルーズ、17:30 / 18:00 / 18:30 / 19:00 のいずれか、大人2名
- 2026-10-19：18:30、大人1名
- 2026-10-19：17:30 / 18:00 / 19:00、大人2名

## LINEの設定
GitHubリポジトリの Settings → Secrets and variables → Actions → New repository secret で、次の2つを登録します。

- `LINE_CHANNEL_ACCESS_TOKEN`
- `LINE_USER_ID`

値はLINE Developersで取得したものを入力してください。コードや公開ファイルには書かないでください。

## 注意
予約サイトの画面仕様が変更された場合、監視プログラムのセレクタ調整が必要になる可能性があります。
